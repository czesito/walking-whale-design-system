# 主張與證據 Assertion and evidence

預設的內容頁。研究顯示，用完整句子當標題、用視覺證據取代條列，聽眾理解與記住的都比較多（Garner 與 Alley，2013）。

## 何時使用

- 大部分的內容頁：標題說結論，body 放一個證據來證明它。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-slide` 或 `ww-slide--evidence` | 版型 |
| `ww-slide__media` | 圖片或 SVG，縮放到 body 的高度；`--frame` 加上標本卡外框 |
| `ww-slide__explain` `ww-slide__point` | 證據旁的一兩句說明，搭配 `ww-split` 兩欄 |
| `ww-figure--annotated` | 引線標註圖（DR-015），最多 5 個標註 |

## 證據可以是

- 產品畫面（見畫面導覽）、流程圖、SVG 圖表、照片、表格、引線標註圖、可調數字、情境切換。

## 規則

- 一頁一個證據。兩個證據就是兩頁。
- 條列不是證據。真的需要列點時，最多 6 項、不巢狀，而且先想想能不能畫成圖。
