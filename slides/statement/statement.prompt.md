# 一句話 Statement

## 何時使用

- 整場簡報最希望聽眾記住、會轉述給別人的那一句。一份簡報一到兩次。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-slide--statement` | 版型 |
| `ww-slide__display` | 那一句，放在 `ww-slide__body` 裡；中文不超過 30 字，英文不超過 16 words |
| `ww-rule` `ww-slide__lede` | 選用的短線與一句補充 |

## 可以發揮的地方

- 用 `ww-em` 標出一個關鍵詞；換成 `ww-on-dark` 製造段落間的停頓。
