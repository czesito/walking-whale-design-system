# 滿版圖片 Image

## 何時使用

- 一張照片比任何文字都有說服力時：現場、產品實物、團隊工作的樣子。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-slide--image` | 版型，圖片佔滿整頁 |
| `ww-slide__media` | 放 `<img>`（自動裁切填滿）或 SVG（保留邊距） |
| `ww-slide__head` | 左下角的卡片：kicker、主張、一句導言 |
| `ww-slide__source` | 右下的圖片來源 |

## 規則

- 加 `data-ww-chrome="off"`。
- `<img>` 一定要有 `alt`；照片要有使用權。
