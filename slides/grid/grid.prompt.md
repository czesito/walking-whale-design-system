# 卡片格 Grid

## 何時使用

- 兩到六個同一類的東西：原則、選項、案例、服務。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-slide--grid` | 版型，放大卡片字級 |
| `ww-grid--2` `--3` `--4` | 欄數；四張卡用 `ww-grid--2` 排成 2 × 2 |
| `ww-card__icon` | 卡片上方的 Lucide 圖示 |

## 規則

- 最多 6 張，每張一個標題加一句話。三張以上的說明合計常常超過預算，細節放講稿。

## 可以發揮的地方

- 加 `data-ww-step` 與 `ww-build--focus`，一張一張講，講過的退成次要色。
