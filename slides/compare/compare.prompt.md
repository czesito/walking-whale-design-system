# 對照 Compare

## 何時使用

- 兩種狀態：現在與導入後、方案 A 與 B。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-slide--compare` | 版型 |
| `ww-compare` | 三欄：左、箭頭、右 |
| `ww-compare__side` `--after` | 一側；`--after` 是白色卡片加 Abyss 頂邊，視線落在這裡 |
| `ww-compare__label` `__title` `__list` | 標籤、一句話、最多三點 |
| `ww-compare__arrow` | 中間的 Lucide 箭頭 |

## 可以發揮的地方

- 同一張圖的前後兩種狀態，改用情境切換（`ww-views`），在同一個位置切換更有對比。
- 示意情境加 `ww-slide__flag`「範例」。
