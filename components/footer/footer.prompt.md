# 頁尾 Footer

## 何時使用

- 每一個公開頁面的最下方。

## 何時不用

- 文章內的區塊結尾，請改用 CTA 模式。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-footer` | Sediment 底，頂部 2px Abyss 線 |
| `ww-footer__grid` | 品牌欄加三欄連結，860px 以下兩欄 |
| `ww-footer__brand` | logo 與品牌簽名 |
| `ww-footer__line` | 品牌簽名，用 tagline |
| `ww-footer__title` | 欄位標題，等寬字 |
| `ww-footer__links` | 連結清單 |
| `ww-footer__legal` | 版權與網域，等寬字 |

## 規則

- 版權列寫法定名稱：「© 年份 走路鯨魚數位體驗有限公司」或「© 年份 Walking Whale Co., Ltd.」（DR-012）。
- 品牌簽名用 tagline 原句，不改寫（content/brand.md）。
- 官方聯絡信箱尚未定案，範例不放電子郵件地址。
