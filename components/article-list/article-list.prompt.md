# 文章列表 Article list

## 何時使用

- 文章、筆記、更新紀錄的索引頁。

## 何時不用

- 案例。案例請用 Case list 模式。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-article-list` | 加在 `<ol>` 上 |
| `ww-article-item` | 一篇文章，整列可點 |
| `ww-article-item__date` | 日期，等寬字 |
| `ww-article-item__main` | 標題、摘要、標籤 |
| `ww-article-item__title` | 標題；裡面的 `<a>` 會延伸到整列 |
| `ww-article-item__excerpt` | 摘要，一到兩句 |
| `ww-article-item__tags` | 標籤清單，放 `ww-chip` |

## 規則

- 日期格式：中文 2026-10-07，英文 Oct 7, 2026（content/zh-tw.md、content/en.md）。
