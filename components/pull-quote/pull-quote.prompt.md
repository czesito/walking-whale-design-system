# 引言 Pull quote

## 何時使用

- 文章或案例中，值得單獨拉出來的一句話。

## 何時不用

- 一般的引用段落，請在 `ww-prose` 裡用 `<blockquote>`。
- 虛構的客戶推薦語。引言必須真實並註明出處。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-pullquote` | 加在 `<blockquote>` 上 |
| `ww-pullquote__text` | 引言本身，用 display 字體 |
| `ww-pullquote__cite` | 出處，等寬字 |

## 規則

- 中文引言不加引號，標點依 content/zh-tw.md。
