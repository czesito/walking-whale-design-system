# 標籤篩選 Tag filter

## 何時使用

- 文章或案例列表上方的篩選。

## 何時不用

- 超過八個選項。請改用搜尋或分類頁。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-filter` | 外框，加 `role="group"` 與 `aria-label` |
| `ww-filter__label` | 標籤，等寬字 |
| `ww-filter__chips` | 按鈕型 chip；只能單選時加 `data-ww-single` |
| `ww-filter__count` | 結果數量，加 `aria-live="polite"` |
