# 數據 Stat

## 何時使用

- 一個值得單獨強調的數字。

## 何時不用

- 沒有來源或無法驗證的數字。每一個數字都要寫出來源或計算方式。
- 範例或估計值卻沒有標示。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-stat` | 上方 1px Abyss 線 |
| `ww-stat__value` | 數字，display 字體、等高數字 |
| `ww-stat__unit` | 單位，放在數字後面 |
| `ww-stat__label` | 這個數字衡量什麼 |
| `ww-stat__note` | 來源或條件，等寬字 |

## 規則

- 數字與單位之間的空格依 content/zh-tw.md 與 content/en.md。
