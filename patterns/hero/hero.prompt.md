# 主視覺 Hero

## 何時使用

- 首頁與重要頁面的開頭。

## 何時不用

- 一頁出現兩次。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-masthead` | 外框；`--split` 加上右側的標本圖版 |
| `ww-masthead__text` | kicker、`ww-hero` 標題、短線、lede |
| `ww-masthead__actions` | 主要與次要按鈕 |
| `ww-plate` | Sediment 圖版，放標誌或案例圖 |
| `ww-plate__caption` | 圖版說明，等寬字 |

## 規則

- 首頁主標用品牌主張原句「先與人同行，再著手系統」，不加句號（content/brand.md）。
- 標題中要強調的詞用 `ww-em`。
- 不要在 Hero 放耳塞年層（DR-014）。
