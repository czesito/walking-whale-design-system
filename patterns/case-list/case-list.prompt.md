# 案例列表 Case list

## 何時使用

- 作品頁與首頁的案例區。

## 何時不用

- 未經客戶同意公開的案例。案例內容必須已在官網公開。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-case` | 圖版加內容的卡片 |
| `ww-plate` | 左側圖版 |
| `ww-case__body` | chip、標題、說明、事實、連結 |
| `ww-case__title` | 案例標題 |
| `ww-case__text` | 一到兩句說明 |
| `ww-case__facts` | `<dl>`：範圍、年份、技術 |

## 規則

- 範例中的案例是示意，不是真實客戶。
