# 團隊 Team

## 何時使用

- 團隊頁與首頁的團隊區。

## 何時不用

- 沒有照片又不想用字首時。可以只列名字與角色。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-person` | 加在 `<figure>` 上 |
| `ww-person__portrait` | 字首或照片，4:5，Abyss 頂邊 |
| `ww-person__name` | 名字 |
| `ww-person__role` | 角色，等寬字 |
| `ww-person__bio` | 一句話說明負責什麼 |

## 無障礙

- 字首只是裝飾，加 `aria-hidden="true"`；照片要寫 `alt`。
