# 聯絡 Contact

## 何時使用

- 聯絡頁與首頁最後的聯絡區。

## 何時不用

- 需要很多欄位的需求問卷。請拆成多步驟並用耳塞年層標示進度。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-split ww-split--start` | 左側表單、右側資訊 |
| `ww-form` | 表單 |
| `ww-contact__details` | `<dl>`：電子郵件、公司、地點、語言 |

## 規則

- 不要寫出尚未確認的承諾，例如回覆時間。
- 電子郵件用官方聯絡信箱 agiblida@gmail.com（content/brand.md）。
