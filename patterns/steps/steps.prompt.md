# 流程步驟 Steps

## 何時使用

- 介紹一個固定的流程，例如合作的三個階段。

## 何時不用

- 讀者正在進行的流程，例如填問卷的第 3 步。請用耳塞年層加文字（DR-014）。
- 超過 6 步。

## Class 與屬性

| Class 或屬性 | 用途 |
|---|---|
| `ww-steps` | 加在 `<ol>` 上，自動排成多欄，窄螢幕一欄 |
| `ww-steps__item` | 一個步驟，上方 1px Abyss 線，編號由 CSS 產生 |
| `ww-steps__title` | 步驟名稱，用 `<h3>` |
| `ww-steps__body` | 一到兩句說明 |

## 規則

- 「我們怎麼開始」用 content/brand.md 的相識、理解、成形，原文不改寫。
